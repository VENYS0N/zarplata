# Калькулятор зарплаты и прибыли

Простой статический сайт для расчёта зарплаты сотрудников с учётом себестоимости товаров, материалов и количества сотрудников. Работает без backend и интернета.

## Запуск

Откройте `index.html` двойным кликом — сайт сразу готов к работе. Сервер не нужен.

Для запуска через локальный сервер (по желанию):

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Что умеет

- **Параметры расчёта** — период, рабочие дни в месяце, НДФЛ, страховые взносы и прочие расходы.
- **Сотрудники** — оклад, отработанные дни, премия; автоматический расчёт начисления, НДФЛ и суммы к выплате.
- **Товары** — количество, себестоимость и цена продажи; расчёт выручки, себестоимости и прибыли по каждой позиции.
- **Материалы** — количество, единица измерения и цена; учёт закупок и расходников в расходах.
- **Сводка** — выручка, расходы, ФОТ, чистая прибыль, рентабельность, структура расходов, прибыль на сотрудника и доля ФОТ в выручке.
- **Тёмная тема** — переключатель в шапке; выбор запоминается, по умолчанию используется системная тема.
- **Сохранение** — данные автоматически хранятся в localStorage браузера.
- **Экспорт / импорт JSON** — резервная копия и перенос данных между браузерами.
- **Печать / PDF** — отдельная печатная версия без кнопок и служебных элементов.

## Формулы

- Начислено = оклад × (отработано дней / рабочих дней) × (1 + премия / 100)
- НДФЛ = начислено × ставка НДФЛ
- К выплате = начислено − НДФЛ
- Страховые взносы = ФОТ × ставка взносов
- Выручка = Σ (количество × цена продажи)
- Себестоимость товаров = Σ (количество × себестоимость единицы)
- Материалы = Σ (количество × цена за единицу)
- Расходы = себестоимость товаров + материалы + ФОТ + взносы + прочие расходы
- Чистая прибыль = выручка − расходы
- Прибыль на сотрудника = чистая прибыль / количество сотрудников
